# Streamlit Learning Repository

## Repository Rule
This rule applies to every README file in this Git repository:

Whenever a change is made to any file in this repository, update the relevant README file(s) with:
- the date
- a short summary of the change
- the file(s) affected

If a README file does not exist in a folder, create one and include this rule.
